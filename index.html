소개

어릴 때부터 과학전람회와 발명·창의력 대회에 나가며 직접 만들어 보는 것을 좋아했습니다. 지금은 앱·웹 개발과 컴퓨터비전·딥러닝 연구를 중심으로 작업합니다.

주로 개인 프로젝트를 처음부터 끝까지 혼자 완성해 왔고, 팀 프로젝트에서는 팀장을 맡아 방향을 정리하고 일정을 이끄는 역할을 좋아합니다.

앱을 출시한 뒤에도 사용자 피드백과 유지보수를 통해 서비스를 개선하고 있습니다. 연구에서는 가설을 세우고 실험 결과를 비교하며 개선 방향을 검토합니다.

관심 분야와 역량

앱 · 웹 개발

아이디어를 실제로 사용하는 서비스로 만듭니다. 기획부터 구현, 출시, 유지보수까지 경험했고 iOS·Android 앱과 실시간 웹 서비스를 직접 배포했습니다.

컴퓨터비전

오픈소스 온디바이스 자세 추정(pose) 모델 여러 개를 직접 벤치마크해 비교하고, 모바일 기기에서 실시간으로 동작하는 영상 분석을 앱에 적용했습니다.

딥러닝

영상 기반 오픈소스 팬샤프닝 모델을 재현하고, 위성영상을 대상으로 구조와 학습 방식을 바꿔 가며 성능을 개선하는 연구를 진행하고 있습니다.

알고리즘

복잡한 문제를 작은 단위로 나누고, 더 효율적인 방법을 비교해 가며 풀어 갑니다. 프로그래밍기초와실습 과목에서 실습조교로 학생들의 실습을 도왔습니다.
